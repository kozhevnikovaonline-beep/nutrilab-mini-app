# NutriLab — Telegram Mini App онлайн-школы нутрициологии

Мини-приложение для Telegram. Пользователь проходит тест «Что мешает вам чувствовать себя лучше?» и получает персональный лид-магнит — гид «Энергия на тарелке». Монеты-«нутрики» он копит в тапалке (как в Hamster Kombat) и обменивает в магазине на продукты школы.

## Что внутри

| Раздел | Возможности |
| --- | --- |
| **Онбординг** | 4 приветственных слайда при первом запуске и подсказки «Как это работает» на каждой странице; повтор — в профиле |
| **Главная** | Приветствие с аватаром из Telegram, поиск, баннер теста или карточка результата с индикатором, лид-магнит, «Новые курсы», ежедневный бонус (серия из 7 дней), задания, блок эксперта |
| **Тест** | 25 вопросов в 5 блоках с текстами из сценария, автопереход, возврат к предыдущему вопросу, сохранение прогресса, 3 варианта результата (0–12 / 13–30 / 31–50), разбивка по сферам, приглашение на консультацию |
| **Лид-магнит** | Гид «Энергия на тарелке»: зоны фокуса по вашим ответам, правило тарелки, меню на 3 дня, ежедневный чек-лист привычек (+20 за привычку). С сервером бот присылает гид в чат |
| **Тапалка** (центр меню) | Монета с наклоном и «+N» в точке касания, мультитач, вибро-отклик, энергия с восстановлением, уровни, бусты «Мульти-тап» и «Запас энергии» |
| **Курсы** | 7 курсов нутрициолога: поиск, категории, вкладки «Описание / Содержание», программа по урокам. Покупка картой в рублях (Telegram Payments) или за нутрики. Бонусы за нутрики: 8 материалов и персональных услуг. «Мои покупки» с кодами доступа |
| **Профиль** | Статистика, результат теста, реферальная ссылка (+1000 за друга), настройки, поддержка, канал |
| **Бот** (`server/`) | Описание и команды, приветствие-воронка с обложкой на /start, кнопка меню, выдача лид-магнита в чат, дожимы через 24 и 48 часов, приём оплаты курсов, проверка подписки на канал, рефералы |

Telegram WebApp API: `requestFullscreen` на телефонах, `expand`, `disableVerticalSwipes`, цвета шапки и фона под светлую и тёмную тему, safe-area под «чёлку» и кнопки Telegram. Также MainButton, BackButton, HapticFeedback, CloudStorage, showConfirm, openTelegramLink, requestWriteAccess и initData.

## Архитектура

```
shared/      Бизнес-логика без зависимостей: тест и подсчёт, экономика, магазин, валидация.
             Один и тот же редьюсер работает и в браузере (мок), и на сервере.
src/
  telegram/  Обёртка над Telegram WebApp + хуки MainButton/BackButton
  api/       ApiClient: MockApiClient (localStorage + CloudStorage) | HttpApiClient (сервер)
  store/     Zustand: состояние, навигация, оптимистичные тапы с пакетной отправкой
  screens/   Главная, Тест, Результат, Гид, Тапалка, Магазин, Товар, Профиль
  components/
server/      Node.js без фреймворков: проверка initData (HMAC), API, бот (long polling), дожимы
```

**Безопасность.** Сервер не доверяет клиенту. Пользователь определяется только по подписанному Telegram `initData` (HMAC-SHA256, проверка срока). Каждое действие проходит строгую валидацию. Баланс считается на сервере. Число тапов ограничено энергией, которая восстанавливается по серверному времени, поэтому накрутить монеты нельзя. Есть rate limit, лимит размера запроса и сериализация операций одного пользователя. Токен бота хранится только на сервере.

**Два режима работы:**
- **Демо** (без `VITE_API_URL`) — всё работает на устройстве. Именно этот режим развёрнут на GitHub Pages.
- **Боевой** (задан `VITE_API_URL`) — данные на сервере, бот выдаёт гид в чат и отправляет дожимы.

## Локальный запуск

Нужен Node.js 20+.

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:5173. Вне Telegram вы входите как «Гость», а кнопки Telegram заменяются HTML-кнопками.

Проверки:

```bash
npm test
```

```bash
npm run build
```

## Деплой на GitHub Pages

1. Запушьте репозиторий в ветку `main`.
2. В GitHub откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` сам прогонит тесты, соберёт проект и опубликует его по адресу `https://<username>.github.io/<repo>/`.
4. Необязательно: в **Settings → Secrets and variables → Actions → Variables** задайте `VITE_BOT_USERNAME`, `VITE_APP_SHORT_NAME`, `VITE_MANAGER_USERNAME`, `VITE_CHANNEL_USERNAME`, а после запуска сервера — `VITE_API_URL`.

## Настройка Telegram-бота

1. В [@BotFather](https://t.me/BotFather): `/newbot` — создайте бота и сохраните токен.
2. `/newapp` — выберите бота, укажите название и описание, загрузите картинку 640×360. В поле Web App URL вставьте адрес GitHub Pages и задайте short name, например `app`. Ссылка на приложение: `https://t.me/<bot>/app`.
3. `/mybots` → бот → **Bot Settings → Configure Mini App → Enable Mini App**, укажите тот же URL. Там же включите **Full-screen mode**: так приложение откроется на весь экран даже из профиля бота.
4. Описание бота, короткое описание, команды и кнопку меню не нужно вводить вручную — их выставляет команда ниже.

### Описание и первое сообщение бота

Тексты лежат в `server/botTexts.ts`:
- **Описание** («Что умеет этот бот?» до нажатия «Запустить») — тест, гид в подарок, нутрики, курсы.
- **Короткое описание** в профиле бота.
- **Первое сообщение воронки** на /start: обложка, приветствие по имени, 3 шага (тест → гид → нутрики), кнопки «Пройти тест и получить гид» и «Курсы нутрициолога».
- **Команды:** /start, /test, /courses.

Впишите токен бота в `BOT_TOKEN` в файле `.env`, затем:

```bash
npm run bot:setup
```

## Запуск сервера (бот + API)

Файл `.env` уже содержит все значения, кроме `BOT_TOKEN`. Впишите токен и запустите:

```bash
npm run server
```

Пока сервер работает, бот отвечает на /start первым сообщением воронки, выдаёт гид в чат, шлёт дожимы и принимает оплату.

### Оплата курсов рублями

1. @BotFather → /mybots → бот → **Payments** → выберите провайдера (например, ЮKassa) и подключите магазин.
2. Полученный токен впишите в `PAYMENT_PROVIDER_TOKEN` в `.env`.
3. Кнопка «Купить за … ₽» откроет нативное окно оплаты Telegram. После оплаты сервер сам выдаст курс и пришлёт сообщение с кодом доступа.

Без токена (и в демо-режиме) кнопка «Купить за ₽» отправляет готовую заявку менеджеру.

Сервер нужно разместить на хостинге с HTTPS: Render, Railway, Fly.io или VPS. Команда запуска — `npm run server`, переменные окружения те же, что в `.env.example`. Укажите `DATA_FILE` на постоянном диске. Затем пропишите адрес сервера в переменную `VITE_API_URL` в GitHub и перезапустите workflow.

Для задания «Подписаться на канал» добавьте бота администратором канала и задайте `CHANNEL_ID`.

## Замена демо-данных

Все тексты, цены, продукты, награды и экономика собраны в `shared/catalog.ts`, `shared/courses.ts` (курсы и их программы) и `shared/quiz.ts`. Фото товаров подключены из Unsplash: если картинка не загрузилась, показывается градиент с эмодзи. Чтобы заменить хранилище на PostgreSQL или Redis, достаточно заново реализовать класс `Db` в `server/db.ts`.

> Тест и гид носят информационный характер и не являются медицинской диагностикой.
